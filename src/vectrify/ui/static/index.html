Snap edges

Automatically match touching edges of the selected paths, pair by pair. Of each touching pair the front contour stays in place; the one behind snaps to it. Regions keep their own colors.

Edges are split where needed, then the rear path's points and handles move onto the front path's. The paths stay independent afterwards. Pins and locks still apply.

Optimize nodes

Fits the selected paths to the reference around them. Each round tries every chosen step and keeps the one that brings the paths closest to the reference; Simplify runs when nothing else helps. Without a reference, Simplify removes points while keeping the paths looking the same.

Fits points and curve handles to the reference by gradient descent, on the GPU when there is one. Straight segments can gain handles where the reference curves.

Fit colours

Solves the flat fill colour of each selected object that best matches the reference, including opacity, clipping and objects in front. Geometry stays fixed.

Settings

Several passes help when fitted objects overlap each other.

Clean up geometry

Removes duplicate and collinear vertices, empty and duplicate paths, and merges compatible neighbouring paths into compound paths. Coordinates are never rounded.

What changes

Only selected objects change. Paths referenced by instances or clips are kept as they are.
