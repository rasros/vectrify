Share boundary

Automatically match touching edges of the two selected paths. The frontmost contour stays in place; the other contour snaps to it. Regions keep their own colors.

Linked endpoints and handles move together, even when only one region is selected. Pins and locks still apply. Save a project to keep these links; SVG preserves the contours but not the editing links.

Smooth / simplify

Replace noisy segments with fewer lines and curves. A higher tolerance smooths more but may drift further from the original outline.

Pinned endpoints stay fixed; holes and separate parts are preserved. Paint and stacking stay unchanged. No reference image needed.

Optimize path

Nudges this path's points, curve handles and colour so the drawing matches the reference more closely. Needs an NVIDIA GPU with CUDA.

Allow changes to

Generate from reference

Traces the reference into new shapes, added as one group at the front.

Settings

Existing objects are not changed. Text in the reference is traced as shapes.

Search improvements

Tries many small random changes to the selected objects, one at a time, and keeps each change that brings them closer to the reference around them. Runs on the CPU; no API key needed.

Allow changes to

Locks, pins and unselected objects stay fixed. Every result is checked as an ordinary edit.

Edit with LLM

Sends the drawing, a render of it and the reference to the model. Changes outside the chosen objects or permissions are left out.

Instruction

Needs an API key or a local server. Locks and pins are enforced.

Fit colours

Solves the flat fill colour of each selected object that best matches the reference, including opacity, clipping and objects in front. Geometry stays fixed.

Settings

Several passes help when fitted objects overlap each other.

Clean up geometry

Removes duplicate and collinear vertices, empty and duplicate paths, and merges compatible neighbouring paths into compound paths. Coordinates are never rounded.

What changes

Only selected objects change. Paths referenced by instances or clips are kept as they are.
